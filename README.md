# Deep Reinforcement Learning algorithms learn important classes of repeated games optimally - theoretical and empirical analysis: Experimental Results
Research files supporting the results presented in my current paper.

The folder "Experiment 1 - Bellman Error" contains the Bellman Errors from the first experiment. Each file in this folder represents the experimental results for different values of v1, v2, v3, and v4 in the payoff matrix of the corresponding game.

Similarly, the folder "Experiment 1 - Q Loss" contains the Q Losses from the first experiment, as defined in the paper.

The folder "Experiment 2 - Losses and Errors" contains all experimental results from the second experiment.
